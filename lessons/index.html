👆 Bosqichni tanlang yoki pipeline'ni ishga tushiring

Har bir bosqich oldingisiga bog'liq. Agar test yiqilsa — build va deploy ishlamaydi. Aynan shu bizni buzuq kodni serverga chiqarishdan saqlaydi.

Amaliyot

Haqiqiy workflow fayl

Mana shu fayl .github/workflows/ci-cd.yml ichida turadi. Har bir qatorni izoh bilan ko'rsatdik.

.github/workflows/ci-cd.yml 
# Workflow nomi
name: CI/CD Pipeline

# QACHON ishga tushadi?
on:
  push:
    branches: [ "main" ]   # main'ga push bo'lganda

jobs:
  # 1-JOB: TEST (CI qismi)
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4          # kodni ol
      - uses: actions/setup-python@v5      # python o'rnat
      - run: pip install -r requirements.txt
      - run: python manage.py test         # TEST!

  # 2-JOB: BUILD & PUSH (CD qismi)
  build-and-push:
    needs: test                          # ← test o'tsagina!
    runs-on: ubuntu-latest
    steps:
      - uses: docker/login-action@v3       # Docker Hub login
        with:
          username: ${{ secrets.DOCKERHUB_USERNAME }}
          password: ${{ secrets.DOCKERHUB_TOKEN }}
      - uses: docker/build-push-action@v6  # build + push
        with:
          push: true
          tags: giyos1/u11_django:latest

Faylni yarating

Loyihada .github/workflows/ci-cd.yml faylini oching va workflow kodini joylashtiring.

Secrets qo'shing

GitHub repo → Settings → Secrets → Actions. DOCKERHUB_USERNAME va DOCKERHUB_TOKEN qo'shing.

Push qiling

git push qiling va GitHub'da Actions tabidan robotning ishlashini real vaqtda kuzating. Tamom! 🎉

deploy:
  needs: build-and-push      # image tayyor bo'lsa
  steps:
    - uses: appleboy/ssh-action@v1
      with:
        host: ${{ secrets.SERVER_HOST }}
        username: ${{ secrets.SERVER_USER }}
        key: ${{ secrets.SERVER_SSH_KEY }}
        script: |
          cd ~/u11_django
          docker compose pull   # yangi image
          docker compose up -d  # qayta ishga tushir
